object SmsParser {
    private val CREDIT_KEYWORDS = listOf(
        "credited", "credited with", "received", "salary", "cashback", "refunded"
    )
    private val DEBIT_KEYWORDS = listOf(
        "debited", "spent", "paid", "sent to", "withdrawn", "purchase", "vpa"
    )

    // 42+ Corporate DLT brand mappings
    private val MERCHANT_ENTITY_MAP = mapOf(
        "kiranakart" to "Zepto",
        "bundl" to "Swiggy",
        "blinkit" to "Blinkit",
        "eternal" to "Zomato",
        "ani technologies" to "Ola Cabs"
    )

    fun parse(raw: String): ParsedTransaction? {
        val amount = extractAmount(raw) ?: return null
        val type = if (isCredit(raw)) "credit" else "debit"
        val tail = extractTail(raw)
        val entity = resolveEntity(raw)
        val dedup = hashSha256("$amount:$tail:$type")

        return ParsedTransaction(
            id = UUID.randomUUID().toString(),
            title = entity,
            type = type,
            amount = amount,
            category = categorize(entity),
            accountTail = tail,
            dedupKey = dedup
        )
    }
}

[QUANTITATIVE // FINANCIAL MATHEMATICS]

Algorithmic Modeling & Burn Math

Aura doesn't make wild guesses. It employs explicit discrete-time cash flow differential calculus to model burn velocity and month-end closing balances.

EQ. 01 // EXPENDITURE VELOCITY

Daily Run-Rate Burn Velocity

Calculated as the normalized sum of discrete debits $D_i$ divided by elapsed calendar days $d_{elapsed}$:

V_{burn} = \frac{1}{d_{elapsed}} \sum_{i=1}^{n} D_i \quad \text{where } D_i \in \text{Debits}
V_burn: Daily run-rate burn speed
d_elapsed: Elapsed days in active month
EQ. 02 // END-OF-PERIOD CONVERGENCE

Projected Month-End Outflow ($P_{EOM}$)

Projects closing expenditures by expanding the current run-rate velocity across remaining calendar days:

P_{EOM} = \left(\frac{\sum D_i}{d_{elapsed}}\right) \times d_{total} + \sum B_{pending}
P_EOM: Estimated end-of-month outflow
B_pending: Known upcoming recurring bills
EQ. 03 // CATEGORICAL MOM DELTA

Categorical Variance Delta ($\Delta_{MoM}$)

Tracks categorical drift across trailing 30-day sliding windows to isolate inflation or impulse anomalies:

\Delta_{MoM} = \left(\frac{C_{current} - C_{prior}}{C_{prior}}\right) \times 100\%
C_current: Active period category sum
C_prior: Baseline prior month sum
EQ. 04 // SOVEREIGN RETENTION RATIO

Net Wealth Retention Ratio ($R_{net}$)

Computes true capital retention after subtracting operational costs from total inflow:

R_{net} = \left(\frac{I_{total} - O_{total}}{I_{total}}\right) \times 100\%
I_total: Liquid credits (Salaries, Dividends)
O_total: Realized debits + fees

[TRANSPARENCY // FAQ AUDIT]

Frequently Asked Questions

Transparency is our core principle. Here are answers to common architectural and security inquiries.

Does Aura Finance ever send my SMS or financial records to a server?

Never. Aura Finance does not even declare the android.permission.INTERNET permission in its AndroidManifest.xml. The Android Linux kernel physically denies network socket creation for this application UID. Non-financial messages (OTP codes, chats) are instantly discarded; only recognized banking debits/credits are indexed locally into SQLite.

How does the Android SMS scanning feature work?

An Android BroadcastReceiver listens for telecom intents. When an SMS arrives from a recognized financial sender ID (e.g., VM-HDFCBK, AD-SBIINB, BP-ICICIB), Aura's pre-compiled regular expression engine extracts the transaction amount, merchant entity, and account tail in under 0.4 milliseconds.

Can I transfer my data to a new phone?

Yes. Under the Settings tab, tap "Export JSON" to generate a portable, sovereign backup file containing your complete ledger, category budgets, recurring schedules, and card mappings. On your new device, tap "Restore JSON" to instantly load your history.

Does it work on iPhones (iOS)?

Yes. On iOS, Aura functions as a full-screen Progressive Web App (PWA). Because Apple restricts background SMS reading to system applications on iOS, Aura provides an instant one-tap SMS clipboard parser and quick add dock, giving iOS users full access to the multi-series analytics and budget engines.

Is there any subscription fee or hidden paywall?

100% Free Forever. Aura Finance has no tier plans, no premium locks, no ads, and no recurring fees. It is built as a pure personal wealth utility tool designed for privacy-conscious individuals.
